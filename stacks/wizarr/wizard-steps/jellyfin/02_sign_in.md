## 🔐 Step 1: Set up your sign-in

Your account is protected by a second check after the password (a code from your phone, or Face ID / Touch ID). Set it up once, now, while you are here.

1. Open **https://sso.kmkdp.com** in a browser.
2. Sign in with the **username and password you just chose**.
3. When asked to add a **second factor**, pick one:
   - **Passkey** (easiest): follow the prompt and approve with Face ID, Touch ID or your phone's unlock.
   - **Authenticator app**: install *Google Authenticator* or *Microsoft Authenticator*, scan the square code, type the six digits.
4. You will see "Authenticated". Done.

If the page asks for a code every time you sign in, tick **"Remember me"**.
