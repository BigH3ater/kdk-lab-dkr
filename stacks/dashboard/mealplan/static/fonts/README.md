# Fonts

Self-hosted for the kitchen board and household page (`../home.css`), so the
pages need no third-party font CDN. Latin subset, variable weight, from the
Fontsource packages `@fontsource-variable/inter@5.2.5` and
`@fontsource-variable/space-grotesk@5.2.5`.

| `space-grotesk-latin-wght-normal.woff2` | Space Grotesk | SIL OFL 1.1, `SpaceGrotesk-OFL.txt` |
